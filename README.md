# 少前2自动借人一键过图脚本（GF2 实时辅助）

少前2（少女前线2：追放）PC 版的半自动打关工具：**关卡你点，剩下的它打**。

它会进本、跳剧情、借好友助战、部署（缺人时从「我的人形」补人）、开打、结算，再回到章节地图挑下一个没打过的关卡。另外带一个「机要密报批量解锁」任务。

本工具基于 [ok-script](https://github.com/ok-oldking/ok-script) 开发，运行时借用已安装的 [ok-gf2](https://github.com/AliceJump/ok-gf2)。它不自带 Python 环境，不含 ok-gf2 的代码，也不含游戏素材。

> **非官方工具**，与 ok-gf2、ok-script 的开发者无关，也与游戏官方无关。用本工具遇到的问题，请到本仓库的 [Issues](https://github.com/sheinlee/gf2-realtime-assist/issues) 反馈，不要提交到 ok-gf2 的仓库或 QQ 群。

## 需要什么

- Windows 10 / 11。
- 少前2 PC 版，游戏语言用**简体中文**（界面文字都按简体中文识别）。
- 先装好 [ok-gf2](https://github.com/AliceJump/ok-gf2/releases)，并且正常打开过一次（第一次打开时它才下载运行环境）。作者用的是 ok-gf2 v1.2.84。ok-gf2 更新后如果本工具打不开，请到 Issues 反馈。
- 游戏画面用 16:9（不低于 1280x720），并关闭 Windows 的自动 HDR。这和 ok-gf2 的要求一样。

## 安装

1. 到 [Releases](https://github.com/sheinlee/gf2-realtime-assist/releases) 下载 `gf2-realtime-assist-v版本号.zip` 并解压，得到 `gf2-realtime-assist` 文件夹。
2. 文件夹放在哪，取决于 ok-gf2 是怎么装的：
   - ok-gf2 用**安装包**（`ok-gf2-win32-*-setup-*.exe`）装的：放在任意位置都行，路径最好全是英文。
   - ok-gf2 是**压缩包解压版**（`ok-gf2-win32-v*.zip`）：把 `gf2-realtime-assist` 文件夹放进 ok-gf2 的文件夹，和 `ok-gf2.exe` 放在同一层。
3. 双击 `启动.bat`，Windows 弹出权限提示时点「是」。游戏本身以管理员身份运行；本工具不提权的话，画面认得出来，但点不动游戏。

本工具可以和 ok-gf2 同时开着，但不要让两边同时操作游戏。

## 实时辅助：点关卡自动打

1. 打开游戏，进到要打的章节地图（主线或活动都可以）。
2. 在本工具左边第二页「实时触发」（英文界面叫 Triggers），打开「实时辅助:点关卡自动打」。
3. 在游戏里点开一个关卡，剩下的交给它。

之后它会这样循环：

```
点「挑战」→ 跳剧情 → 借好友助战 → 部署 → 作战开始 → 自动战斗 → 结算
  → 回到章节地图，挑下一个没打过的关卡
```

一章打完，会自动进下一章（往期活动和主线都支持）。纯剧情关（按钮是「观看」）只跳剧情。

几点说明：

- **你动键鼠时它不点**。你停手 2.5 秒后，它接着来。借人途中你操作了游戏（不只是切过来看看），它就停手，交给你处理。
- **卡住了会停手等你**。画面认不出或按钮点不动时，它会存一张现场图，然后停手。5 分钟没有进展会弹通知提醒（可以在设置里改时间或关掉）。
- 要停下来，在「实时触发」页关掉它的开关，或者点程序里的停止按钮。

### 先改成你要借的人

默认借**威玛西娜**（元素条第 2 列），备选**可露凯**（第 6 列），作战效能至少 10000。请在「实时触发」页这个任务的设置里改成你要的：

| 设置 | 默认 | 说明 |
|---|---|---|
| 助战角色名 | 威玛西娜 | 留空就不借助战 |
| 备选助战角色名 | 可露凯 | 好友列表里没有够强的主选时借她；可以填多个，用逗号隔开，按先后优先；留空 = 不用备选 |
| 助战元素筛选 | 2 | 先点元素条第几个图标缩小范围（1～6）；0 = 不筛选 |
| 备选助战元素筛选 | 6 | 备选在元素条第几列；0 = 和主选在同一列里一起找 |
| 助战最低战力 | 10000 | 作战效能低于这个数就换下一张卡；0 = 不看战力 |
| 找不到目标时借最强的 | 开 | 实在找不到要借的人，就借战力最高的其他助战 |
| 自动选关 | 开 | 回到章节地图后自动挑下一个没打过的关卡 |
| 自动点挑战 | 开 | 替你点「挑战」进本；关掉就由你自己点进本 |
| 记住打过的关卡 | 开 | 打赢的关卡记下来，下次打开也不重打 |
| 界面等待(秒) | 1.5 | 每次点击后多等多久；电脑或游戏卡顿时调大 |

助战列表里只显示作战效能，不显示名字，所以它是逐张点开卡片读名字来认人的，换了皮肤也认得出。

不确定角色名怎么写时：手动进到任意一关的部署界面，在「任务」页把「测试:好友助战」的「助战角色名」清空，然后运行它。日志里会列出每张卡的作战效能和名字。

### 默认会用掉的东西

- **情报拼图不够时用补给补充**（默认开）：点「挑战」时如果弹出「情报拼图补充」，它会选中间那格（补充道具）并确认，补上后接着打。右边那格（晶体）它一下都不点。中间那格是 0 个、认不准，或者补过一次还弹框时，它会停手等你。不想用掉补充道具，就把这一项关掉。
- **缺人时从我的人形补人**（默认开）：本关要求的出击人数不够时，从「我的人形」里挑作战效能最高的补上。

## 机要密报批量解锁

它会逐条解锁机要密报里的项目并领取奖励，**会消耗各项目的专用情报道具**。

1. 先关掉「实时辅助:点关卡自动打」，免得两个任务抢着操作。
2. 在游戏里打开「机要密报」卡片列表，手动滚到最上面。也可以停在已经打开的项目详情页，从当前进度继续。
3. 在本工具的「任务」页选「机要密报:批量解锁」，点开始。
4. 按住 **F8** 可以随时停止，也可以点程序里的停止按钮。

已归档和已完成的项目会跳过；材料不足时会取消并跳过该项目。认不出的弹窗会让它停下，交给你处理。翻到底或者翻页不动时，它会存一张现场图并停下。结束后请自己检查列表里还有没有没解锁的项目。

这个任务最近一版的改动还没在游戏里完整跑过，第一次用时请在旁边看着。

## 文件放在哪

设置、日志和截图都在本工具文件夹里，和 ok-gf2 的互不影响：

- `configs/`：设置，以及打过的关卡记录。
- `logs/`：日志，主要看 `ok-script.log`。
- `debug_tiles/`：卡住时的现场图，以及认不出的界面截图（「记录认不出的界面」默认开，最多存 60 张）。可以随时删掉。

反馈问题时，请附上 `logs/ok-script.log` 和 `debug_tiles/` 里对应时间的图。截图里可能有你的游戏昵称或 UID，发出去之前自己看一眼。

## 更新

下载新版压缩包，把里面的文件复制到原来的文件夹、覆盖旧文件即可。`configs/` 里的设置和关卡记录会保留。

## 已知限制

- 只支持简体中文客户端。
- 只借一个助战。部署位置只保证放得上去，不保证战术上合理。
- 元素图标、左上角菜单的位置是按 16:9 画面量的，别的比例可能点不准。
- 日常、推图等其他功能请直接用 ok-gf2。本工具只做上面两件事。
- 本工具用到了 ok-gf2 内部的代码（ok-script 运行时和它的基础任务类）。ok-gf2 大改之后，本工具可能要跟着更新。
